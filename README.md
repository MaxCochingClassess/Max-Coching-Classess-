MAX Coaching Classes — GitHub Pages Website
Publish on GitHub Pages
Create a new GitHub repository, for example max-coaching-classes.
Upload index.html, style.css, script.js and the assets folder.
Open Settings → Pages.
Under Build and deployment, choose Deploy from a branch.
Select main and / (root), then Save.
GitHub will provide the live website URL.
